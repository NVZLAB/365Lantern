## Verified

- Clean detached checkout of the source commit; self-contained Windows x64 publish.
- Source desktop build and 437 automated checks, plus GitHub Windows build.
- Packaged PowerShell imports Graph Authentication and ExchangeOnlineManagement.
- Packaged synthetic UI checks, including asynchronous import, expected failure-burst
  finding, report navigation, light/dark views, response approval and password handoff.
- All 1,315 inventory hashes and ZIP entries checked; no excluded evidence, private
  keys/certificates or source-control folders. CycloneDX 1.6 schema validation passed.
- Gitleaks scans of reachable history, source/staged changes, completed Actions logs
  and package text found no leaks. Targeted tenant-reference scans also passed.
- NuGet desktop dependency advisory query returned no listed vulnerabilities.
- Initial GitHub CodeQL C# scan passed with no reported alerts; GitHub secret scanning
  and Dependabot alerts were empty at release time. These checks have limited coverage.
- The maintainer confirmed this exact ZIP passed the listed clean Windows 11 VM tests
  as a standard user: launch, included synthetic import, Microsoft sign-in/read-only
  collection, and report/evidence export. This is maintainer-reported testing, not an
  independently observed recording or a test of every tenant configuration.
- Actual packaged update-check code discovered `0.1.0-alpha.1` through GitHub's public,
  unauthenticated API. Before publication it correctly excluded the draft.
- Public GitHub asset digest matches the tested local ZIP.

## Repository protections

Public access, private vulnerability reporting, secret scanning/push protection,
Dependabot alerts/security-fix PRs and weekly CodeQL C# scanning were verified enabled.
Main requires a pull request, up-to-date successful GitHub Actions `build` check,
resolved conversations and linear history; force-push/deletion are disabled and
administrators are subject to protection. Zero external approvals are required for
this solo-maintainer project. Automated dependency PRs are not automatically merged.

## Scope and remaining work

This is not a security certification, penetration test or exhaustive vendor dependency
review. The exact-package VM confirmation did not enumerate live tests for every
response action. Continue disposable-account/device validation before relying on
response in production. Licensing/retention gaps, false positives/negatives, API delays,
large-tenant performance, accessibility, cancellation/offline scenarios and installer
signing remain ongoing alpha work. There is no stable release or support SLA.

The tag and downloadable bytes remain fixed. The repository's follow-up commit records
this release in CHANGELOG.md and advances source development to `0.1.0-alpha.2`;
those documentation/version changes do not replace the tested alpha.1 package.
